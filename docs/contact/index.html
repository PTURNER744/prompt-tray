Did Windows block the beta?

Microsoft Defender SmartScreen may show “Windows protected your PC” when an app is unsigned or unfamiliar. Smart App Control may also block unsigned apps on Windows 11. The current GitHub beta has no code signature.

If Windows blocks the download or launch, leave its protection enabled and get in touch. Tell us which warning you saw and which version of Windows you’re using.
