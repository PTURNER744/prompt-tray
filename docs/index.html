From something useful to something reusable.

Keep Prompt Tray in the notification area or show it on the taskbar for mouse access.

↓

Save it

Drag in a file, image, or selection of text. Add an item by hand or turn on clipboard auto-save for new copies.

⌕

Find it

Open the launcher with Ctrl+Alt+P. Search by text, filename, or category and navigate with the arrow keys.

↗

Use it

Press Enter to copy text or open a file. Copy a file into Explorer, grab its path, or drag it straight into another app.

Your library lives on your PC.

Keep a link to a file where it is, or store a copy in Prompt Tray so it stays available if the original moves.

Does it save everything I copy?

Clipboard auto-save starts off. Switch it on from Options or the tray menu to capture new text, file links, and images. You can pause it at any time.

Where are my items stored?

Your library is stored under %LOCALAPPDATA%\PromptTray. File links point to their originals. Stored file copies and saved images live in the library’s Files folder.
