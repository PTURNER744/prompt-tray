Privacy policy

This policy covers the Prompt Tray Windows app published by Ironworks Technology. Effective 17 November 2026.

What the app stores

Prompt Tray saves the text, categories, file paths, file copies and images that you add to your library. It uses these items to let you find, preview, open and reuse them. Linking a file saves its path. Choosing to store a copy saves a separate file.

Clipboard auto-save is off by default. When you enable it, the app reads new clipboard items while it is running and saves supported text, file links and images locally. Turn it off in Options or the notification-area menu to stop capture. Items already saved remain in the library.

Where it is kept

The app keeps the library and settings in local storage for your Windows user account. The index and its previous revision are stored as readable JSON. File copies and saved images are stored as ordinary local files. Access is governed by Windows file permissions.

The app has no account system or telemetry. It does not transmit your library or clipboard content to Ironworks Technology or to a cloud service. When you copy, paste, open or drag an item into another app, Windows and that app handle it according to their own settings. Windows clipboard history or sync can apply to items you copy if you have enabled those features.

Access and delete your items

View and manage saved items in Prompt Tray. Deleting an entry removes it from the current library. The previous revision can still contain the entry, and a stored file copy can remain in the Files folder.

To clear the whole library or remove leftover copies, exit Prompt Tray, then remove the library folder or the relevant files in Windows. For the portable app, open %LOCALAPPDATA%\PromptTray. Windows may place the Store edition's data inside its per-user package storage. Removing a file link from Prompt Tray leaves the original file at its original location.
